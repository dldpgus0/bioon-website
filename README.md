# BIO:ON Insight — website

Bilingual (KO/EN) home for **BIO:ON Insight**, a weekly biotech & pharma newsletter: every Tuesday morning, last week's three biggest stories, explained with the Korean market angle and what they mean for your career.

Designed and built by [이예현 (Yaehyun Lee)](https://github.com/dldpgus0) together with Claude Code, as part of an AI-assisted media workflow (research → newsletter → card news → web).

## Features

- **Korean / English** routing (`/ko`, `/en`) with automatic language detection
- **Insight archive** — every issue imported straight from the Stibee email HTML, shown exactly as subscribers received it, with KO/EN editions paired by date
- **Wiki** (`/wiki`) — every issue's three stories re-indexed by category (FDA Approvals, Clinical Trials, Market Trends, Pipeline Analysis) and by company, drug and regulator, with a page per category and per entity. The index shows the four categories, the most-covered names and the latest stories, with the full name list folded away. Data: `src/content/wiki.json` — **add the new issue's three stories there after each import**, or it won't appear in the wiki, the archive's category filter or related insights
- **Issue pages** open with the editor's takeaway (the issue's own "💡 에디터 인사이트", quoted verbatim), list the issue's stories with category and entity links, and end with sources and up to three related issues (shared companies/drugs first, then topics)
- **Ask BIO.ON** — question search over the archive, ranked by each issue's AI keywords, summaries and answerable questions (`src/lib/search.ts`, runs in the browser; `?q=` links are shareable)
- **Career** section (LinkedIn, résumé, interviews, industry trends) with category filters
- **Waitlist** — upcoming guides and AI tools (`src/content/waitlist.json`) show a "Waitlist open" button that opens an email-capture modal (`src/components/Waitlist.tsx`); sign-ups use the subscribe API with source `waitlist:<id>`
- **References** — each issue page lists the issue's sources (title, publisher, link) parsed from its email HTML (`getIssueReferences` in `src/lib/content.ts`)
- **Share previews** — issue pages set article Open Graph tags and generate a 1200×630 image with the title in Pretendard (`insight/[slug]/opengraph-image.tsx`). Set `NEXT_PUBLIC_SITE_URL` if the site moves to a custom domain
- **Dark mode** — header toggle via `next-themes`; colours are CSS tokens redefined under `.dark` in `globals.css`
- **Interview question bank** (`/career/interview`) — 34 role-tagged mock interview questions with answer points, each built from a newsletter issue (`src/content/interview-bank.json`), with a random 5-question practice mode
- **FAQ** (`/faq`) — newsletter, subscription, AI use and career questions, with FAQPage structured data
- **Lead magnets** — the resources page (acronym cheatsheet, interview question pack with role competency questions and STAR, trial/approval data guide, pipeline & deal tracker .xlsx, English CV template .docx + checklist, industry glossary) and the interview bank's answer points unlock after an email sign-up. The subscribe API sets a signed HttpOnly cookie (`src/lib/lead.ts`); `/api/resources/[id]` and `/api/interview-points` check it server-side, and gated content is never in the page HTML. Resource data lives in `src/content/` (`acronyms.json`, `interview-competency.json`, `downloads/*.md`); the Excel and Word files are generated by `python3 scripts/build-downloads.py` (needs openpyxl and python-docx; recalculate the xlsx with LibreOffice afterwards)
- **RSS** — `/feed.xml` (Korean) and `/feed.xml?lang=en`, the latest 10 issues
- **Analytics skeleton** — `src/hooks/useAnalytics.ts` logs events (filters, search, subscribe clicks and submissions, unlocks, downloads) to the console and forwards them to GA4 (`gtag`) or Mixpanel once either snippet is added
- **Subscribe** form wired to the Stibee API, including an inline form under the latest issues on the home page
- Planned: AI topic tagging, KO→EN translation pipeline, AI résumé feedback, AI mock interview, JD analyzer, archive chatbot, subscriber segments (student / industry)

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Vercel

## Working on it

```bash
npm install
npm run dev        # http://localhost:3000
npm run import     # re-import issues from the newsletter/template folder and newsletter-src/
```

| Path | What it holds |
| --- | --- |
| `src/app/[lang]/` | Pages, one folder per route |
| `src/dictionaries/` | UI copy in Korean and English |
| `src/content/insight.json` | Issue metadata (generated by `npm run import`) |
| `src/content/career/{ko,en}/` | Career posts in Markdown |
| `public/newsletters/` | Web copies of the email issues (generated) |
| `newsletter-src/` | Web-only issue sources kept in the repo (the welcome letter, always #1, and the English editions of the first ten weekly issues), read by `npm run import` |
| `scripts/prepare-logos.ps1` | Turns the logo PNGs in `brand-src/` into transparent web assets |

Optional: `LEAD_COOKIE_SECRET` signs the lead-magnet unlock cookie (falls back to `STIBEE_API_KEY`).

Environment variables for the subscribe form: `STIBEE_API_KEY`, `STIBEE_LIST_ID`, and optionally `STIBEE_GROUP_KO` / `STIBEE_GROUP_EN` (Stibee group IDs; sign-ups from each language site are assigned to that group).

# BIO:ON Insight — website

Bilingual (KO/EN) home for **BIO:ON Insight**, a weekly biotech & pharma newsletter: every Tuesday morning, last week's three biggest stories, explained with the Korean market angle and what they mean for your career.

Designed and built by [이예현 (Yaehyun Lee)](https://github.com/dldpgus0) together with Claude Code, as part of an AI-assisted media workflow (research → newsletter → card news → web).

## Features

- **Korean / English** routing (`/ko`, `/en`) with automatic language detection
- **Insight archive** — every issue imported straight from the Stibee email HTML, shown exactly as subscribers received it, with KO/EN editions paired by date
- **Ask BIO.ON** — question search over the archive, ranked by each issue's AI keywords, summaries and answerable questions (`src/lib/search.ts`, runs in the browser; `?q=` links are shareable)
- **Career** section for aspiring bio/pharma professionals (LinkedIn, résumé, interviews, industry trends)
- **Subscribe** form wired to the Stibee API
- Planned: AI topic tagging, KO→EN translation pipeline, AI résumé feedback, AI mock interview, archive chatbot, paid resources

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Vercel

## Working on it

```bash
npm install
npm run dev        # http://localhost:3000
npm run import     # re-import newsletter issues from the newsletter/template folder
```

| Path | What it holds |
| --- | --- |
| `src/app/[lang]/` | Pages, one folder per route |
| `src/dictionaries/` | UI copy in Korean and English |
| `src/content/insight.json` | Issue metadata (generated by `npm run import`) |
| `src/content/career/{ko,en}/` | Career posts in Markdown |
| `public/newsletters/` | Web copies of the email issues (generated) |
| `scripts/prepare-logos.ps1` | Turns the logo PNGs in `brand-src/` into transparent web assets |

Environment variables for the subscribe form: `STIBEE_API_KEY`, `STIBEE_LIST_ID`, and optionally `STIBEE_GROUP_KO` / `STIBEE_GROUP_EN` (Stibee group IDs; sign-ups from each language site are assigned to that group).

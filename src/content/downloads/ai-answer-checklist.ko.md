## 이 체크리스트를 만든 이유

AI에게 논문이나 임상 결과를 물으면 답이 아주 그럴듯하게 나와요. 문제는 **그럴듯한 것과 맞는 것이 다르다**는 거예요. 저는 BIO:ON의 모든 글에 출처를 다는 원칙을 지키려고, AI로 찾은 내용도 원문까지 직접 확인해요. 이 체크리스트는 그 확인 과정을 정리한 거예요.

아래 항목은 연구 결과와 공식 데이터베이스의 안내를 바탕으로 했어요. 각 사이트의 화면과 기능은 바뀔 수 있어서, 맨 아래 출처의 확인일(2026년 10월 1일)을 함께 적었어요.

## 왜 확인해야 할까: 연구로 본 숫자

- **의학 글 속 참고문헌:** ChatGPT(GPT-3.5)로 짧은 의학 글 30편을 만들게 한 연구에서, 참고문헌 115개 중 **47%는 존재하지 않는 가짜**였고, 46%는 실제로 있지만 내용이 부정확했어요. 정확한 것은 **7%뿐**이었어요 [1].
- **모델 버전에 따른 차이:** 42개 주제로 짧은 문헌 리뷰 84편을 만들게 한 연구에서, 인용 636개 중 가짜 인용은 GPT-3.5가 **55%**, GPT-4가 <strong>18%</strong>였어요. 실제로 있는 논문을 인용한 경우에도 GPT-3.5는 43%, GPT-4는 24%에 중요한 오류가 있었어요 [2].

**제가 배운 점:** 새 모델일수록 오류가 줄지만 0이 되지는 않아요. 그래서 "이 모델은 믿을 만하다"보다 <strong>"매번 원문을 확인한다"</strong>는 습관이 더 중요하다고 생각해요.

## 1. 논문 인용 확인

- [ ] **DOI가 있으면 직접 열어 보기.** 주소창에 `https://doi.org/` 뒤에 DOI를 붙여 열어요. 형식이 틀렸거나 존재하지 않는 DOI면 해당 논문으로 연결되지 않아요 [3].
- [ ] **DOI가 없으면 PubMed에서 찾기.** PubMed의 **Single Citation Matcher**에 저널 이름, 연도, 저자 등 아는 정보만 넣어 검색해요 [4].
- [ ] **세부 정보 대조하기.** 논문이 실제로 있어도 제목, 저자, 연도, 저널이 틀린 경우가 많아요 [1][2]. 네 가지를 하나씩 대조해요.
- [ ] **내용 대조하기.** AI가 "이 논문에 따르면"이라고 한 내용이 초록이나 본문에 정말 있는지 확인해요.
- [ ] **철회 여부 확인하기.** Retraction Watch 데이터베이스는 2023년 Crossref가 인수해 누구나 무료로 쓸 수 있어요 [5]. 철회된 논문을 근거로 쓰지 않도록 확인해요.

## 2. 임상시험 주장 확인

- [ ] **NCT 번호 확인하기.** ClinicalTrials.gov에 등록된 임상시험은 **"NCT" + 숫자 8자리** 형식의 고유 번호가 있어요 [6]. AI가 말한 번호를 ClinicalTrials.gov에서 검색해 실제 기록이 나오는지 봐요.
- [ ] **시험 설계 대조하기.** 1차 평가변수, 비교군(위약 또는 표준치료), 단계, 진행 상태가 AI 설명과 같은지 확인해요.
- [ ] **"결과가 나왔다"는 주장 확인하기.** 결과 탭이 있는지 보고, 없다면 논문이나 회사 보도자료에서 확인해요. ClinicalTrials.gov 결과 탭에는 수치만 있고 **해석이나 결론은 들어가지 않아요** [7].
- [ ] **허가 주장은 규제기관 원문으로.** "FDA 승인을 받았다" 같은 내용은 FDA, EMA, 식약처 발표에서 직접 확인해요. 방법은 같은 자료실의 **임상·허가 원자료 찾기 가이드**에 있어요.

## 3. 유전자 이름 확인

- [ ] **HGNC에서 공식 기호 찾기.** 사람 유전자의 공식 이름과 기호는 HUGO 유전자 명명 위원회(HGNC)가 정하고, genenames.org에서 검색할 수 있어요 [8].
- [ ] **옛 이름 주의하기.** HGNC는 엑셀이 유전자 기호를 날짜로 바꾸는 문제를 막기 위해 일부 기호를 바꿨어요. 예를 들어 SEPT로 시작하던 기호는 SEPTIN으로, MARCH로 시작하던 기호는 MARCHF로 바뀌었어요 [9][10]. AI나 예전 논문은 옛 기호를 쓸 수 있어요.
- [ ] **엑셀에 붙여넣을 때 날짜 변환 확인하기.** 유전자 목록이 담긴 엑셀 보충자료를 가진 논문 중 <strong>19.6%</strong>에서 이런 변환 오류가 발견됐다는 연구가 있어요 [11].

## 4. 숫자와 날짜 확인

- [ ] **1차 출처에서 다시 찾기.** 매출, 계약 금액, 환자 수, 승인 날짜는 회사 보도자료, 공시, 규제기관 발표에서 다시 찾아요.
- [ ] **단위와 기준 확인하기.** 통화(달러·유로·원), 단위(백만·십억), 기준 연도나 분기가 맞는지 봐요.
- [ ] **두 출처 대조하기.** 서로 독립된 출처 두 곳에서 같은 숫자가 나오는지 확인해요.

## 5. 질문할 때부터 줄이는 법

제가 AI에게 질문할 때 쓰는 방법이에요. 오류를 없애 주지는 않지만 확인을 훨씬 쉽게 만들어 줘요.

- **식별자를 달라고 하기:** "출처마다 DOI나 PMID, NCT 번호를 붙여 줘"라고 요청해요. 그러면 위 체크리스트로 바로 확인할 수 있어요.
- **모른다고 말하게 하기:** "확실하지 않으면 모른다고 말해 줘"라고 덧붙여요.
- **원문을 먼저 주기:** 가능하면 논문 초록이나 보도자료 원문을 먼저 붙여 넣고, 그 안에서만 답하게 해요.
